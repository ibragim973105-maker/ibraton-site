# IBRATON — сайт концепции

Статический адаптивный сайт на русском языке. Не требует сборки, серверной части, базы данных или ключей API.

## Локальный просмотр

Откройте `index.html` в современном браузере.

## Публикация

Файлы можно разместить в любом статическом хостинге после проверки владельцем аккаунта. Для GitHub Pages потребуется создать репозиторий, загрузить `index.html` в корень и включить Pages в настройках репозитория. Подключённый GitHub-аккаунт сейчас не содержит доступных репозиториев, а доступный набор действий не позволяет создать новый репозиторий автоматически.

## Важное ограничение

Это информационный прототип. В нём нет криптоконтракта, кошелька, финансовых операций, платежей, хранения персональных данных или подключения к блокчейну. Не добавляйте такие функции без отдельной оценки безопасности, законодательства и соответствующих возрастных/правовых требований.
