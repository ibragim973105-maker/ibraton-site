# IBRATON — статус проекта

Дата фиксации: 8 ноября 2026 г.

## Подтверждено
- Подготовлен статический сайт с адаптивной вёрсткой.
- Сформирована визуальная система: тёмный фон, золотые акценты, геометрический знак IBR.
- Описаны предварительные направления: Tools, Wallet (только концепция), Market, Connect.
- Добавлены предупреждения о статусе проекта и безопасности.

## Не выполнено и не должно подразумеваться
- Публичная публикация сайта и постоянный URL.
- Создание/развёртывание смарт-контракта.
- Выпуск токена или подтверждение его предложения.
- Подключение к блокчейну, кошельку, платежам или биржам.
- Аудит кода, юридическое заключение или проверка товарного знака.

## GitHub
Интеграция GitHub подключена, но при проверке список доступных репозиториев пуст. Среди доступных GitHub-действий нет создания нового репозитория. Поэтому файлы подготовлены для загрузки, но не опубликованы.

## Следующие безопасные шаги
1. Владелец аккаунта создаёт пустой репозиторий `ibraton-site` в GitHub.
2. Загружает `index.html` и `README.md` в корень репозитория.
3. Включает GitHub Pages для ветки `main`, папки `/root`.
4. Проверяет сайт на телефоне и компьютере, прежде чем делиться адресом.
5. Дополняет документацию фактами и ответственными контактами только после их подтверждения.
